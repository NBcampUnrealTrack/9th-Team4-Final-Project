# 즉시 시전 모션

작성: 이정준 (구현: Codex), 2026-10-28

## 설정

1. 기존 근접공격 몽타주를 복제해 연출 전용 몽타주를 만든다.
2. 복제본의 공격 판정/Gameplay Event Notify를 제거한다. 참조 애니메이션 시퀀스 안의 Notify도 확인한다.
   원본 근접공격 에셋을 변경하지 않는다.
3. 이동에 영향을 주지 않는 루트 모션 없는 모션을 사용한다. 루트 모션 몽타주는 코드에서 재생하지 않고 경고한다.
4. 해당 스킬 GA의 `NF → Skill → Animation`에서 설정한다.
   - `Cast Montage`: 연출 전용 몽타주. 기본 None, 미지정 시 기존 동작 유지.
   - `Cast Montage Play Rate`: 기본 1.0.
   - `Cast Montage Start Section`: 기본 None, 필요할 때 섹션 이름 지정.
5. 몽타주의 스켈레톤 및 Slot이 기존 캐릭터 AnimBP에서 지원되는 것을 사용한다.
   기존 근접공격과 같은 ASC의 메시/연결 AnimInstance를 대상으로 재생한다.

상체만 움직이고 싶다면 기존 AnimBP에서 지원하는 상체 Slot을 사용한다.
기존 AnimBP가 해당 Slot을 지원하지 않으면 플레이어 담당의 설정이 필요하다. 이번 작업은 AnimBP/플레이어 코드를 수정하지 않는다.
몽타주는 Notify를 정상 실행하므로 공격용 몽타주를 그대로 지정하면 실제 공격 이벤트가 발생할 수 있다.
원본 자동 선택이나 Notify를 무시하는 기능은 추가하지 않았다.

## 실행 시점과 네트워크

- 공통 `CommitExecute`에서 기존 비용/쿨다운 처리를 유지하고 활성 액티브 스킬의 모션을 요청한다.
- 조준 홀드/시전 대기 중에는 재생하지 않는다. 입력 해제형은 해제 후 스킬이 실제 Commit할 때 재생한다.
- GA가 `CommitAbility`를 호출하지 않는 커스텀 BP는 이 공통 경로를 타지 않는다.
- 모션을 기다리거나 모션 종료로 GA를 종료하지 않는다. 기존 효과는 즉시 실행된다.
- 몽타주 설정/재생 실패는 스킬 효과를 막지 않는다. `[SkillAnimation]` 경고로 설정 문제를 확인한다.
- 패시브 장착/발동 연출은 기존 Gameplay Cue 경로를 사용한다.
- 서버가 짧게 유지되는 `NF_SkillCastVisual` 액터로 재생 설정을 관련 클라이언트 모두에 전달한다.
  기본 GAS 몽타주 복제는 로컬 소유 Avatar를 제외하므로 서버 전용 GA의 모션은 별도 전달한다.
- 연출 액터는 초기 복제와 BeginPlay로 재생하고, 소유자/메시 초기화가 늦으면 최대 0.5초 재시도한다.
  GameState의 서버 시간을 사용할 수 있으면 네트워크 지연만큼 재생 시작 위치를 보정한다.
- GA가 바로 종료되어도 모션은 끝까지 재생하며, 같은 슬롯의 다른 몽타주가 시작되면 중단될 수 있다.
- 캐릭터 이동/입력 잠금이나 공격 GA 호출은 추가하지 않는다.
- 장착 해제/EMP로 GA가 끝나도 이미 시작된 일회성 모션은 별도로 중단하지 않는다.
- 몽타주는 반복되지 않는 단발 연출용으로 설정한다.

## 검증

`NF.Skills.Animation.ImmediateCast` 자동화 테스트 소스:
미지정 시 기존 실행, 사망 상태의 사용 실패 시 연출 없음, Commit 후 연출 액터 생성,
즉시 스킬이 모션 종료를 기다리지 않음, 다음 사용 시 다시 연출 생성.

빌드/자동화 실행/실제 포즈 및 멀티플레이 재생은 아직 확인하지 않았다.
컴파일 후 서버+클라이언트 PIE에서 소유자와 다른 플레이어의 모션이 각각 한 번 보이는지,
기존 근접공격 피해 이벤트가 발생하지 않는지, 효과 발생 시점이 그대로인지 확인한다.
