# HUD 연동 요청 — 장착 무기와 탄창 잔탄 변경 알림

작성일: 2026-10-25  
대상: 무기 담당자

## 목적

현재 장착한 주무기 종류와 탄창 잔탄을 HUD에 표시하기 위한 변경 알림 요청입니다.

## 현재 사용할 수 있는 데이터

| 정보 | 기존 조회 경로 |
|---|---|
| 장착 무기 | `UNF_WeaponComponent::GetEquippedWeapon()` |
| 무기 DataAsset | `ANF_WeaponBase::GetWeaponData()` |
| 무기 종류 | `UNF_WeaponDataAsset::WeaponType` |
| 현재 탄창 잔탄 | `ANF_WeaponBase::GetCurrentAmmo()` |
| 탄창 크기 | `UNF_WeaponDataAsset::MagazineSize` |

이번 필수 HUD 요구에는 무기 아이콘·개별 무기 이름·예비 탄약량·재장전 상태 표시가 포함되지 않습니다. 무기 종류와 탄창 잔탄을 위한 DataAsset 필드는 현재 존재합니다.

## 현재 부족한 부분

- `EquippedWeapon`에는 `OnRep_EquippedWeapon()`이 있지만 VM이 외부에서 구독할 장착 변경 알림은 없습니다.
- `CurrentAmmo`는 일반 `Replicated`이며 외부에서 구독할 탄약 변경 알림은 없습니다.

위 내용은 작성일의 C++ 소스 기준입니다. 이미 별도로 제공하는 공개 이벤트가 있다면 알려주세요.

## 요청 사항

1. 무기 장착·교체·해제를 구독할 수 있는 공개 변경 알림을 제공해주세요. 해제 상태도 식별할 수 있어야 합니다.
2. 현재 탄창 탄약이 변경될 때 구독 가능한 알림을 제공해주세요.
3. 발사·재장전 완료 등 서버에서 값이 변경되는 경로와 클라이언트에 복제된 시점에 필요한 알림이 발생해야 합니다.
4. 알림은 새 값을 전달하거나, 기존 Getter로 최신값을 읽도록 변경 사실만 알려줘도 됩니다.
5. 구독 해제가 가능해야 합니다. 무기 교체 시 UI VM이 이전 무기 이벤트를 해제하고 새 무기로 연결하겠습니다.
6. 무기 참조와 데이터가 클라이언트에서 준비되는 순서를 알려주세요. 장착 알림 시 데이터가 아직 준비되지 않을 수 있다면 준비 완료를 확인할 경로가 필요합니다.

요청은 모델 변경 알림 제공입니다. 모델에서 UI VM이나 Widget을 직접 호출할 필요는 없습니다. 구체적인 OnRep·Delegate 구현 방식은 담당 파트에서 결정해주세요.

## 데이터 흐름과 UI 담당 범위

```text
WeaponComponent / WeaponBase 변경 알림
    → WeaponStatusViewModel이 기존 Getter로 현재값 조회
    → FieldNotify
    → 무기 종류·탄창 잔탄 표시
```

UI에서 최초 현재값 조회, 이벤트 구독·해제, 무기 교체 시 재연결, 무기 미장착 상태 정리와 표시 문구 변환을 구현합니다. 예를 들어 탄창 크기까지 표시하면 `24 / 30` 형식으로 구성할 수 있습니다.

## 전달받고 싶은 내용

- 장착 변경·탄약 변경 Delegate 또는 공개 이벤트 이름
- 각 알림의 인자와 발생 시점
- 클라이언트 복제 후 알림 여부
- 장착 알림 시 무기와 DataAsset 준비 여부

## 완료 확인
